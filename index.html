God of War Chains

Reverse-engineering God of War 1 (PS2, 2005): the Kratos model, animation system, combo chains, and Blades of Chaos — decoded from the disc and rebuilt as a browser lab.

kratos-lab — model, animation & combo tester

Textured, skinned, animated Kratos with a PS2 button pad, real clip timing, branch panel, and chain-simulated blades.

Designer tweak sheets (.twk)

One browsable sheet per combat animation: real clip data (id, duration, blend-in, keyframe rate) + branch topology with inputs and windows, provenance-tagged real vs inferred. Index.

About game assets: this public build contains code and documentation only. The extracted game data (models, textures, animations) is copyrighted and is not distributed — the viewer will tell you so if you open it here. To see it live, clone the repo, extract assets from your own disc (see the repo docs), and run node tools/kratos-lab/server.js.
