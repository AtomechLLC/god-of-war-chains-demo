<objective>
Add the chainglow additive overlay and switch both chain textures to WAD-sourced decode. This is the CHAIN-02 vertical slice: an additive pass sharing the link ribbon's exact vertex bytes shows the decoded heat-ramp colors (black -> red -> orange -> yellow, hottest texel (254,229,0)) near the blade. Because the glow is coplanar with the depth-writing link pass, WebGL's default `depthFunc(LESS)` would reject it wherever links wrote depth — so this plan sets `gl.depthFunc(gl.LEQUAL)` once at init (the GS ZTST=2 GEQUAL analog). Both textures move off the hardcoded `assets/weapon/GFX_*.bin` fetches onto the decoded `texName -> TXR -> GFX/PAL` resolve chain, consuming the `filter`/`texName` fields flagged unused in 02-REVIEW IN-01 (WAD bytes verified byte-identical to the extracted files this session).

Purpose: CHAIN-02 — "a chainglow additive overlay pass (depth-write off) shares the ribbon UVs and shows the real heat-ramp colors from the decoded texture." Also pins CHAIN-01's pixel ground truth (chainlink 512x32, 32px U-periodicity) via a texture known-answer and sources the chainlink texture CHAIN-01 renders.

Output: `FxParse.parseTxr` + wad.test.js TXR/texture known-answers + WAD-sourced `chainlinkTex`/`chainglowTex` + parameterized `makeTex` + drawFx PASS 2 + `depthFunc(LEQUAL)`.

Depends on 03-01 (shares app.js drawFx and the chain vertex buffer; PASS 2 reuses PASS 1's exact upload — Wave 2).
