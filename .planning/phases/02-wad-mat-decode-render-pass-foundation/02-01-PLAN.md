Parsers additions (tools/kratos-lab/parsers.js):
```javascript
// record = { idx, off, tag, flags, size, name, dataOff }
Parsers.parseWad(buf /* Uint8Array */)            // -> record[]  (throws on overrun)
Parsers.resolve(records, name, fromIdx)           // -> record | null
// backward scan from fromIdx-1; targets only size > 0 && (tag === 0x1E || tag === 0x70)
```

FxParse (tools/kratos-lab/fxparse.js — pure decode, no GL, no DOM):
```javascript
// mat = { name, off, mode: "usual"|"additive"|"subtract"|"strange",
//         disableDepthWrite: bool, filter: "linear"|"nearest", haveTexture: bool,
//         texName: string, blendColor: [r,g,b,a], materialColor: [r,g,b],
//         floatUnk: number, gameFlags: number, rawFlags0: number }
FxParse.decodeFlags(flags0, recName)              // -> { mode, disableDepthWrite, filter, haveTexture }; throws on 0 or >1 mode bits
FxParse.buildMats(records, buf)                   // -> { byName: {name -> mat}, list: mat[] }  (byName: last record wins, per gow1 server-instance rule)
FxParse.enumTuples(list)                          // -> [{ mode, depthWrite: bool, filter, layerCount, materials: string[] }]
```
Both files end with: `if (typeof module !== "undefined" && module.exports) module.exports = <Name>;`
