FxParse.parseLight(buf, rec) -> { anchor:[3], color:[3], intensity, range, evidence:[...] }  (from 06-02)
  LeftBladeLight  @0x6a60 -> anchor (-0.32,-8.0,1.0), color (1.0,0.622,0.288), intensity 2.5, range 160
  RightBladeLight @0x6b20 -> identical values. Locate via Parsers.parseWad(wadBuf) by name, tag 0x1e.
  These are REAL/decoded (byte-exact) -- do NOT hardcode the constants; call parseLight so provenance stays in the decoder.

Mesh shader (app.js:124-152):
  vsrc: gl_Position = uMVP*(uModel*vec4(aPos,1)); passes vNrm, vUV, vCol. ADD a varying `vWorld = (uModel*vec4(aPos,1)).xyz` for the per-fragment light vector.
  fsrc: computes `vec3 c = tex*ao*diff*1.75 + spec` then gl_FragColor = vec4(c,1). ADD the two blade-light terms to `c` BEFORE the final assignment.
  Point-light term (RESEARCH Pattern 6): for each blade light i:
    Lp = uLightPos[i] - vWorld ; d = length(Lp) ; atten = max(0.0, 1.0 - d/uLightRange[i]) ;
    c += uLightColor[i] * uLightIntensity[i] * max(dot(n, normalize(Lp)), 0.0) * atten ;
  No shadows (D-06). Naive gamma-space add (REND-01 -- no bloom/tonemap; the existing shader already does *1.75 and a heat mix in gamma space).

Light world position: xformM(bladeSim[key].mat, anchor) each frame (bladeSim[key].mat is the live blade world matrix; anchor is the decoded blade-local light offset). Pass as uLightPosL/uLightPosR. Uniforms feed `prog` (the mesh program); update them where prog uniforms are set per rendered frame.

Attenuation math is tested in light.test.js (06-02): atten(0)=1, atten(range)=0, atten(range/2)=0.5 -- the shader mirrors this exactly.
