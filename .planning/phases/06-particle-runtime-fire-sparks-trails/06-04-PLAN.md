<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Particles pool → GL buffer | Packed vertex data feeds bufferSubData; any NaN would corrupt the draw — guarded at spawn (06-01) |
| new pool pass → shared GL state | additivePremult sets blendFunc/depthMask; a leaked state breaks the next frame's depth clear (Pitfall 3) |
| continuous spark emission → pool | Unbounded spawn would grow the buffer/CPU cost (perf DoS) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | Denial of Service (state leak) | pool pass leaving depthMask false / non-FUNC_ADD | mitigate | Blend/depth only via Fx.applyMaterial; drawFx ends with Fx.restoreFxState; fxState() clean-check between frames |
| T-06-04-02 | Denial of Service (perf) | unbounded spark spawn | mitigate | Pool hard-capped (POOL_CAP) + life cull (06-01); emission gated to attacking ticks |
| T-06-04-03 | Denial of Service (render corruption) | NaN in packed verts | mitigate | Particles.spawn skips non-finite (06-01); rampColor bounded |
| T-06-04-SC | Tampering | supply chain | accept | Zero packages; classic <script> tags only |
</threat_model>
