Particles (IIFE global + module.exports) — proposed surface:
  makePool({ maxParticles }) -> {
    spawn(p),           // p = { pos:[3], vel:[3], size, life, color:[4], kind }; drops/rejects if over cap OR any non-finite; age starts 0
    integrate(dt),      // pos+=vel·dt; vel+=g·dt (g INFERRED, e.g. [0,-Gy,0]); age+=dt; cull age>life; dt MUST be Loop.STEP
    burst(n, template, sampler), // spawn up to n particles from template with per-particle jitter from sampler (sampler=()=>0 in tests → deterministic, D-07)
    particles,          // live array (JSON-dumpable: pos/vel/age/life/size/color/kind) — no GL handles
    count               // current length
  }
  spawnAnchor(bladeMat16, fxcMatrix16) -> [x,y,z]   // xformM(bladeMat, fxcMatrix.slice(12,15)) — world spawn pos (D-03 / SC1)
  stretchAxis(vel3, camUp3) -> [x,y,z]              // normalize(vel) if |vel|>eps else camUp (velocity-aligned spark, CLAUDE.md Part 3)
  variantFor(moveName) -> "BFT" | "BGT"            // INFERRED move→trail-variant table (TRL-02)
  glowGain(isIdle, { rest, hot }) -> number         // isIdle ? rest : hot (INFERRED dark↔hot rule, CHAIN-03 / D-05)
  rampColor(t) -> [r,g,b]                            // t in [0,1] age fraction; white-hot(0)→orange→ember(1) (INFERRED, TRL-01 / A3)
  fireBindings(db) -> [{ emitter, particle, shapeRef }]  // join db.fxc→db.ptc by matching shapeRef NAME (D-08 / Pitfall 6)

xformM reference (app.js:540 — replicate the 3×4 transform inside spawnAnchor):
  out = [ m0·x+m4·y+m8·z+m12, m1·x+m5·y+m9·z+m13, m2·x+m6·y+m10·z+m14 ]

Loop.STEP = 1/60 (NTSC 60Hz tick; rates/lifetimes are tick units — Phase-5 D-05).

Determinism boundary (D-07): the pure module stays deterministic. Per-particle randomness is INJECTED by the caller passing a sampler; tests feed sampler=()=>0 (fixed jitter), exactly as chain.test.js feeds fixed curve arrays. Keep Math.random OUT of the tested paths.

Real vs INFERRED (label in code + evidence comments): INFERRED here = gravity constant, jitter ranges, variantFor table, glowGain rest/hot, rampColor stops, particle life/size defaults. REAL = the spawnAnchor transform math + the FXC matrix translation it reads. NEVER fabricate a real-tagged effect color (Pitfall 4) — rampColor is explicitly INFERRED.
