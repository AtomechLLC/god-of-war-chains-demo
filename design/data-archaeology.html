Data Archaeology

How the numbers behind the kratos-lab were dug out of the God of War (2005) disc: the finds, the dead ends, and the techniques. Everything below is tagged real (decoded bytes), inferred (a model or interpretation), or dead end (proven absent).

The TWK tweak system

The game's designer parameters live in a tree format inside part1.pak: magic 0xFEDCBA98, nested named directories, and data records keyed by a 32-bit hash of the parameter name — h = h·127 + c per character (from mogaika's god_of_war_browser). Names are hashed away, but the hash is weak: we cracked 680 of 1,408 unique keys by hashing every string in the game executable (plus %d-numbered forms), and two stronger techniques:

  • Suffix extension with modular inversion — 127 is odd, so prefixHash = (h − H(S)) · 127−len(S) mod 232 is exact: guess a suffix, solve for the prefix, look it up. This named Angle Offset, Scale/Offset X/Y/Z, Hit Sound 1–6, Template 0–19 and more — each corroborated by consecutive-hash families that cannot collide by chance.
  • Pair-delta analysis — 504 per-animation records pair up with a constant hash difference 0x75B55A5. That delta has exactly one vocabulary solution: the suffixes " Tween" / " Cycle" (values fit: 0.025–0.3 s transition blends). The base names are designer-tool strings that never shipped. semantically identified, individually unrecoverable

All 78 decoded instances are browsable as .twk sheets.

Root motion: the hidden controller channel

The skeleton is authored fully in place — the root joint never translates, and even the run cycle has zero locomotion in any joint. no joint-based root motion But each attack's ANM act carries an unread type-5 datatype whose state holds per-frame floats for the pelvis plus a controller translation trio — component 420 (lateral), 421 (vertical) and 422 (forward), baked at 30 Hz. the engine's character-controller track

The vertical channel is the jump data: jumpUp rises 0 → 9.37 units (0.67 m), jumpDoubleAir adds a second linear boost of 0.77 m, and airV1 (the air slam) opens at 9.66 — the single-jump apex, corroborating the read. Landings and ground moves carry no 421 at all: the descent belongs to engine physics under the decoded /GlobGame/ Gravity = 50, and air combos hover by engine float. rise + gravity hover model

Hit volumes: hand-authored, not the weapon

The big attacks don't test the blade at all. /TweakTemplates/Concussion/ instances are named per attack ("BF Plume C", "Hero Impale1") and carry the authored AoE: Start/End radius in meters, duration, packed damage, and knockback impulse vectors — anchored at the character (zeroJoint), with a paired "F" template sized for the visual ring (always bigger than the hit). Plume: 2.0 m hit, 4.5 m flash

The Angle field authors the fairness asymmetry directly: every hero concussion is 0 = full 360°, while enemy attacks are 30–45° cones you can dodge around.

Melee swings resolve in engine code against the swept blade (no per-frame hit-window data exists anywhere in the ANM — the 60 Hz candidate tracks proved to be byte-identical exporter boilerplate on every act).

The units bridge

Tweak values are meters; the mesh is not. Kratos' standing head-top measures ≈28 mesh units, so at an assumed 2.0 m tall, 1 m ≈ 14 units. Cross-validated two independent ways: chain-link pitch counted from footage (0.061 × height ≈ 1.71) matches the decoded Segment Length interleaved (0.25/2 × 14 = 1.75), and the decoded Link Diameter lands on the square-texel rule within 4%. bridge both anchors
